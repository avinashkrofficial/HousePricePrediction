# Real Estate Analytics Platform

An **AI-powered Flask web application** that predicts **house prices**, estimates **rental values**, and calculates **home loan EMIs** for properties in major Indian cities like **Bengaluru** and **Delhi**.  
Built with **Machine Learning**, **Flask**, and an interactive **frontend UI**, this platform helps users make smarter real estate decisions.

---

## Features

### House Price Prediction
Predict property prices based on:
- Location  
- Total square feet  
- Number of bedrooms (BHK)  
- Number of bathrooms  
- City (Bengaluru / Delhi)

### Rent Estimation
Automatically calculate estimated monthly rent based on:
- Property price  
- BHK size  
- City-wise and BHK-based rental yield  

### EMI Calculator
Get instant EMI details including:
- Monthly EMI  
- Total interest payable  
- Total payment (principal + interest)  
Customizable by interest rate, down payment %, and loan tenure.

### Multi-City Support
- Bengaluru  
- Delhi  

### Web Interface
- Responsive and clean frontend built with HTML, CSS, and JavaScript  
- Integrated seamlessly with Flask backend  
- Displays results interactively without reloading the page
